# Stuti Dutta's Portfolio Website

A modern, responsive portfolio website showcasing my work as a UX/UI Frontend Engineer. Built with React, TypeScript, and Tailwind CSS.

## Features

- Modern UI/UX design
- Responsive layout
- Interactive animations
- Project showcase
- Skills section
- Contact form
- Downloadable resume

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vite

## Local Development

1. Clone the repository
```bash
git clone https://github.com/Stutidutto/portfolio
cd portfolio
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Build for production
```bash
npm run build
```

## Deployment

The website is deployed using Vercel for optimal performance and reliability.
